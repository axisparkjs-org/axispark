# Parameters

Http Plugin provides a set of decorators implemented through the `@axisparkjs/engine` package that allow you to extract parameters from the request and validate them. These decorators can be used in your controller methods to easily access and validate request parameters.

<table>
    <thead>
        <tr>
            <th>Decorator</th>
            <th>Description</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td><code>@Context()</code></td>
            <td>Extracts the full context of the current request / execution</td>
        </tr>
        <tr>
            <td><code>@Request()</code></td>
            <td>Extracts the HTTP request object from the context</td>
        </tr>
        <tr>
            <td><code>@Response()</code></td>
            <td>Extracts the HTTP response object from the context</td>
        </tr>
        <tr>
            <td><code>@Body()</code></td>
            <td>Extracts the body from the HTTP request. It can be used to extract the request body, map it to a DTO, and validate it.</td>
        </tr>
        <tr>
            <td><code>@Path(field: string)</code></td>
            <td>Extracts a specific field from the HTTP request path parameters. If the field is not found, it will return undefined.</td>
        </tr>
        <tr>
            <td><code>@Query(field: string)</code></td>
            <td>Extracts a specific field from the HTTP request query parameters. If the field is not found, it will return undefined.</td>
        </tr>
        <tr>
            <td><code>@Header(field: string)</code></td>
            <td>Extracts a specific field from the HTTP request headers. If the field is not found, it will return undefined.</td>
        </tr>
        <tr>
            <td><code>@Ip()</code></td>
            <td>Extracts the IP address of the client making the request.</td>
        </tr>
        <tr>
            <td><code>@Session()</code></td>
            <td>Extracts the session object from the HTTP request. If the session options are disabled, it will return undefined.</td>
        </tr>
        <tr>
            <td><code>@Cookie(field: string)</code></td>
            <td>Extracts a specific field from the HTTP request cookies. If the cookie is not found or the session options are disabled, it will return undefined.</td>
        </tr>
        <tr>
            <td><code>@UploadedFile(field: string)</code></td>
            <td>Extracts the first file uploaded in a <code>multipart/form-data</code> field. If the field has no file or the <code>fileUpload</code> option is disabled, it will return undefined. See <a href="./file-uploads">File uploads</a>.</td>
        </tr>
        <tr>
            <td><code>@UploadedFiles(field?: string)</code></td>
            <td>Extracts the files uploaded in a <code>multipart/form-data</code> field, or every uploaded file when no field is given. If the <code>fileUpload</code> option is disabled, it will return undefined. See <a href="./file-uploads">File uploads</a>.</td>
        </tr>
    </tbody>
</table>

## Usage

Here are some examples of how to use the parameter decorators in your controller methods:

```ts
@Get()
get(@Context() context: HttpContext, @Request() req: HttpRequest, @Response() res: HttpResponse) {...}

@Get()
getTodos(@Header('authorization') auth: string, @Query('limit') limit: string) {...}

@Get(':index')
getTodoByIndex(@Path('index') index: number, @Query('includeDetails') includeDetails: string) {...}

@Post()
addTodo(@Body() todo: { task: string }) {...}

@Put(':index')
updateTodo(@Path('index') index: string, @Body() updatedTodo: { task: string }) {...}

@Delete(':index')
removeTodo(@Path('index') index: string, @Ip() ip: string) {...}
```
