The plugins that do not depend on each other run `onRegister` and `onStart` at the same time, level by level of the dependency graph, and `onStop` level by level in reverse order, so independent connections (Redis, Kafka, RabbitMQ) no longer start and stop one after the other. New `pluginLifecycle` option of the application: `'sequential'` keeps running them one by one in dependency order.
