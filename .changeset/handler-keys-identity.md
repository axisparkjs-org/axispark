The cached results and the rate limit buckets of two classes with the same name are no longer shared. `CacheProcessor` and `RateLimitProcessor` identify the class of the handler with the new `ClassIdentifier`: the first class registered with a name keeps the name, so the keys of applications without repeated names do not change, and the next ones get `<name>#<n>` in registration order, the same in every process of the application, so shared stores such as Redis keep working between replicas.
