The packages are compiled to ES2023 instead of ES2016, so the published code uses the native `async`/`await`, optional chaining, nullish coalescing, class fields and object spread. The stack traces point to the original methods instead of the `__awaiter` helper, and the asynchronous request pipeline runs without the generator wrappers. The packages now require a runtime with ES2023 support, already guaranteed by `"engines": { "node": ">= 24" }`. The class fields keep their current semantics (`useDefineForClassFields: false`), so the decorators and the DI container behave as before. The `tsconfig.json` of the templates generated by `axispark create` use the same target.
