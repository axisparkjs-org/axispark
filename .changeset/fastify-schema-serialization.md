The Fastify adapter can serialize the JSON responses with the schemas of the OpenAPI document, using the `fast-json-stringify` serializer of Fastify instead of `JSON.stringify`. Enable it with the new `serializeResponses` option of the OpenAPI plugin. The properties that are not in the schema are not sent. New optional `HttpAdapter.registerResponseSchemas()` and `OpenApiDocumentGenerator.generateResponseSchemas()`.
