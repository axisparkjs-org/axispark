The cached `ExecutionPlan` of a handler no longer keeps the execution context of the first request, with its request, response, scoped container and signal, for the life of the process. The plan has a `handler` property with the class and the property key of the handler instead of `context`.

Breaking changes: code that reads `plan.context` of an `ExecutionPlan` must read `plan.handler`, which only has `target` and `propertyKey`.
