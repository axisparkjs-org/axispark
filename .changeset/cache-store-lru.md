`InMemoryCacheStore` has a maximum number of values, 10 000 by default: when a new value exceeds it, the least recently used value is removed, so many distinct keys can not exhaust the memory. New `maxEntries` option of `InMemoryCacheStore`, and `MemoryStore({ cache: { maxEntries } })` to set it in the plugin options; `Infinity` keeps the previous unbounded behaviour.
