The dependencies of a constructor, and the `inject` tokens of a factory provider, are resolved in parallel with `Promise.all`, so the asynchronous factories that a class needs run at the same time at startup and in scoped resolutions. The circular dependency and scope checks are kept: each dependency is resolved in a fork of the resolution chain, so dependencies of the same class can wait for the singletons created by each other.
