The `package.json` of every package declares `repository` (with the folder of the package), `homepage`, `bugs` and `keywords`, so the npm page links to the source code, the website and the issue tracker. The production versions are published with provenance statements generated by GitHub Actions. Every package declares its public entry point in `exports`: importing the package (`@axisparkjs/http`) and its `package.json` work as before, but importing an internal file of `lib` (for example `@axisparkjs/http/lib/...`) now fails with `ERR_PACKAGE_PATH_NOT_EXPORTED`. Import everything from the package root. The published tarballs no longer contain `tsconfig.build.json`.
