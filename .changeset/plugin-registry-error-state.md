`PluginRegistry` no longer stops the lifecycle of the remaining plugins when one plugin is in the `Error` state: the failed plugin is skipped and the rest of the plugins run their `onStart` and `onStop` methods, so their servers start and their connections are closed on shutdown. A plugin whose required dependency is in the `Error` state is skipped too, and moves to the `Error` state with the new `PluginDependencyFailedError`.
