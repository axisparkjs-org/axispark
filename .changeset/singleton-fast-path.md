Resolving a singleton that is already created, or a value, no longer goes through several async functions: `Container.resolve()` and `Injector.get()` return it directly, without starting a resolution chain. New `Container.tryResolve(token)` and `Injector.tryGet(token)`, which return synchronously the value or the created singleton of a token, also through `useExisting` aliases, or `undefined` without creating anything.
